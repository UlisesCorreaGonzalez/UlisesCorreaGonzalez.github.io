Project Overview

Tech Stack: JavaScript, Three.js, HTML5, CSS3, Node.js, WebSockets (Socket.IO)

Dino.io is a full-stack 3D multiplayer web game featuring an online shared world, live player synchronization, and dynamic gameplay mechanics. The frontend utilizes Three.js for immersive 3D graphics rendered directly in the browser and is hosted via GitHub Pages, while a custom Node.js backend manages real-time WebSocket communication and is deployed on Render.

Key Features

  • 3D Graphics & Rendering: Implemented using Three.js and vanilla JavaScript to handle custom game loops, lighting, and interactive 3D canvas rendering.
  • Real-Time Multiplayer: Bidirectional event synchronization using WebSockets (Socket.IO) allowing multiple users to connect and play simultaneously in a shared world.
  • Dynamic Gameplay & Progression: Interactive mechanics featuring player evolution, size scaling, scoring systems, and upgrade shops.
  • Cloud Architecture & Deployment: Clean separation of concerns with a static client on GitHub Pages and a persistent backend service hosted on Render using automated configuration.

This project demonstrates the successful integration of advanced frontend graphics, real-time networking, and cloud deployment pipelines, resulting in a fully interactive, production-ready web application.
