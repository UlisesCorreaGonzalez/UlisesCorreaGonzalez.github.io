About Me

I am an Information Technology Engineer from the Instituto Tecnológico Superior de Irapuato, focused on software development, web applications, process automation, and system integration.

During my academic training and professional internship, I developed applications and tools aimed at improving operational processes, including an inventory management system used in a real business environment, Excel-based automation solutions using VBA, and database-driven applications.

I also develop personal projects to expand my experience in modern web technologies. One of my current projects is Dinosaur.io, a browser-based multiplayer game that I am actively developing using JavaScript, Three.js, Node.js, and WebSockets. The project allows me to work on frontend development, interactive 3D graphics, real-time communication, backend services, and web deployment.

My experience includes programming logic, problem-solving, data handling, web development, automation, and integrating software with real-world systems. I enjoy building practical applications while continuously exploring new technologies and improving my development skills.
